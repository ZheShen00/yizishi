## 示例：一个 AI 文档助手定下来的叫法

起一份新表时可以从这里抄。「来源」写清楚是谁定的、在哪个提交或门禁里，后来的人才知道能不能改。下表的来源栏是示意写法。

| 用这个 | 不用这些 | 适用范围 | 来源 / 裁决 |
|---|---|---|---|
| 对话 | 会话、线程、thread | 全站 | 全站去 AI 腔那次统一（提交 abc1234） |
| 文件 | 产物、artifact | 全站 | 同上 |
| 在线编辑 | 网页端编辑 | 文档 | 编辑器的产品名 |
| 历史版本 | 版本链 | 全站 | 与文件面板的版本标签一致 |
| 智能体 | agent | 全站 |  |
| 确认中 / 已生效 / 未生效 / 无法确认 | 没生效、没法确认、确认不了 | AI 改动卡片 | 用户裁决；门禁锚着这一套状态词 |
| 无法 | 没法 | 全站 | 项目约定 |
| 已发出（没有回执的动作） | 已撤销、已恢复、已替换 | 撤销、替换、发给编辑器的命令 | 门禁锚着「已发出 N 步撤销」 |
| 待填 | 要你补、待你补全、需要你补全 | 草稿里的空位 | 文案审查（提案） |
| 智能整理 | （功能名，不改） | 文件库 | 用户裁决；门禁锚着 |
| 字数 | 字符数、长度 | 文档统计 | 提案，待定 |
