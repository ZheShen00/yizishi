## 台湾版译文

1. 上傳檔案失敗，請檢查網路後再試一次。
2. 預設儲存到「我的文件」資料夾。
3. 該影片目前暫不支援在行動裝置上播放。

## 说明

这三句不能只做「简→繁」逐字转换。台湾版的差别不只在字形，更在词汇：直接字形转换会得到「上傳文件失敗，請檢查**網絡**後重試」「**默認保存**到我的**文件夾**」「該**視頻**暫不**支持**在**移動端**播放」，其中「網絡」「文件夾」「默認」「視頻」「支持」「移動端」都是大陆或港澳用法，台湾用户一眼能看出是转出来的。

逐条改动：

| 原文 | 台湾版 | 理由 |
| --- | --- | --- |
| 上传文件 | 上傳檔案 | 台湾软件界面里 file 一律作「檔案」，用「文件」会被理解为文书/公文 |
| 网络 | 網路 | 「網絡」是港澳用法 |
| 重试 | 再試一次 | 保留「重試」也可接受，但台湾界面语感更常用「再試一次」 |
| 默认 | 預設 | 「默認」在台湾几乎不用 |
| 保存 | 儲存 | 台湾 Windows/App 标准用语 |
| 我的文档 | 我的文件 | 对应系统文件夹「我的文件」；「文档」在台湾指文件/公文 |
| 文件夹 | 資料夾 | 台湾固定译法 |
| 视频 | 影片 | 台湾说「影片」，不说「視頻」 |
| 暂不支持 | 目前暫不支援 | support 在台湾作「支援」，不作「支持」 |
| 移动端 | 行動裝置 | 台湾说「行動裝置」；语境明确指手机时可简作「手機」 |

## 两点提醒

- 若这是按钮或 Toast，长度敏感：① 的「再試一次」可缩为「重試」，③ 的「行動裝置」可缩为「手機」，语义都不变。
- ② 中的「我的文件」是 Windows 繁体中文版的系统文件夹名；若指的是 App 自己的目录，写成「我的檔案」更准确，请按实际指向二选一。标点保持全形，「」不必改成 “”，台湾本身就用「」。
