台湾版（zh-TW）三句：

```
① 上傳檔案失敗，請檢查網路後重試。
② 預設儲存到「我的文件」資料夾。
③ 此影片暫不支援在行動裝置上播放。
```

换掉的词和理由（只列必须换的，其余照字转繁）：

| 简体 | 台湾 | 理由 |
|---|---|---|
| 文件（file） | 檔案 | 台湾的「文件」指 document，file 一律写「檔案」。这三句里两种都有，正好分开 |
| 网络 | 網路 | 「網絡」是香港写法，台湾写「網路」 |
| 默认 | 預設 | |
| 保存 | 儲存 | 软件里的 save 台湾写「儲存」，「保存」偏「妥善保管」 |
| 文档（document） | 文件 | 简体「文件」和繁体「文件」不是一个东西。「我的文档」要是照字转成「我的檔案」，台湾用户会以为是另一个位置 |
| 文件夹 | 資料夾 | |
| 视频 | 影片 | 「視頻」台湾不用；「視訊」只指实时通话 |
| 移动端 | 行動裝置 | 也可以写「手機版」，全站选一种；「移動端」别留 |
| 支持（某功能） | 支援 | 「支持」只留给「支持某个意见」 |
| 该 | 此 | 「該」偏公文；台湾界面提示多写「此」。项目里已经用「該」就跟着用 |

标点没动：全角、「」不换成『』（这三句没有嵌套引号）、句末句号照留。小地方：「檢查網路」和「檢查網路連線」在台湾都常见，看项目里别的报错怎么写的，选一种。

两处要你定：

1. ② 的「我的文档」指哪个文件夹。我按「产品自建的保存文件夹」处理，写成「我的文件」，这一处是猜的。
   - 产品自建、名字可以定：就用上面的「我的文件」。
   - 是 Windows 系统的 Documents：跟系统显示的名字走（新版系统显示「文件」，旧版是「我的文件」），不要自己另译，否则用户在资源管理器里找不到。
   - 名字在代码或服务端写死、改不了：界面照原样显示，别译。
2. ③ 的「行動裝置」：这句如果只在手机 App 里出现，台湾用户会想「我拿的就是手机」，写「手機」更直接也更短：「此影片暫不支援在手機上播放。」网页版也共用这一句时，就保留「行動裝置」。

顺带一句，不算翻译，改不改你定：① 把失败原因只归到网络，服务端超时也走这句的话，可以写「上傳檔案失敗，請重試；多次失敗請聯繫[填：客服或管理員]。」

行业风格：手机 App（台湾市场），依据是你说的是「我们 App」、句子里出现「移动端」「上传文件」。用词按 zh-TW 常用词表加手机 App 的台港差异一节；项目自己如果有繁体术语表，以它为准。
