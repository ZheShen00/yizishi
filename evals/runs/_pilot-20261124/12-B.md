① 「上傳檔案失敗，請檢查網路後重試。」
② 「預設儲存到『我的文件』資料夾。」
③ 「該影片暫不支援在行動裝置上播放。」

## 換掉的不只是字形

| 原詞 | 台灣版 | 說明 |
|---|---|---|
| 上傳 / 文件 | 上傳 / **檔案** | 台灣講「文件」多半指公文、文書；電腦裡的 file 一律叫「檔案」 |
| 網路 | **網路** | 「網絡」是港澳／中國大陸用法 |
| 默認 | **預設** | 「默認」在台灣幾乎沒人這樣說 |
| 保存 | **儲存** | 「保存」偏指食物、古蹟的保存；存檔動作用「儲存」 |
| 文件夾 | **資料夾** | 「文件夾」是中國大陸說法 |
| 我的文檔 | **我的文件** | 對應台灣版系統的資料夾命名 |
| 視頻 | **影片** | 台灣的「視頻」指視訊會議訊號，不是 video |
| 支持 | **支援** | 功能層面的 support 用「支援」；「支持」偏表態支持某人的意思 |
| 移動端 | **行動裝置** | 台灣說「行動」不說「移動」 |

## 兩點順帶提醒

- **巢狀引號**：原文是「」包「」，台灣排版慣例外層「」、內層用『』，所以第二句寫成「預設儲存到『我的文件』資料夾。」若你們的文案規範一律只用「」，維持單層也可以，但兩層都用「」在台灣讀起來會卡。
- **資料夾名稱**：若這句指的是系統上那個實際存在的資料夾，台灣版 Windows／macOS 的顯示名稱是「文件」，可寫成「預設儲存到『文件』資料夾。」；若指的是 App 自己的概念性位置，用「我的文件」較貼近原意，也不會和「檔案」混淆。
