# 台灣版首頁 Banner 文案

## 結論先講

原文不能只做簡繁轉換。三句話裡有兩個是台灣會直接被公平會盯上的寫法（「日息」、「秒到」），還有一個是金額不實的風險（50 萬沒寫幣別）。改法不是換個說法修飾，而是換一套台灣消金廣告的揭露邏輯：**利率用總費用年百分率、速度用「最快 X 分鐘」、額度加 NT$ 並掛「依審核結果為準」**。

## 一、可直接上線的版本

### 方案 A（建議｜額度當主視覺）

> **最高可貸 NT$50 萬**
> 總費用年百分率 [X.XX]% 起・核准後最快 [X] 分鐘撥款
> `[ 立即試算 ]`
>
> 小字：實際核貸金額、利率及相關費用依審核結果為準。借款有風險，請審慎評估自身還款能力。

### 方案 B（速度當鉤子）

> **線上申貸，核准後最快 [X] 分鐘撥款**
> 最高可貸 NT$50 萬・總費用年百分率 [X.XX]% 起
> `[ 立即申請 ]`

### 方案 C（費用透明當鉤子，轉換略低但客訴最少）

> **借多少、還多少，一次算清楚**
> 最高 NT$50 萬・總費用年百分率 [X.XX]% 起
> `[ 試算月付金 ]`

三版共用同一行警語，字級不得小於相鄰說明文字（法務通常會要求至少副標的六成，且顏色對比要夠，不能灰到看不清）。

`[X.XX]` 和 `[X]` 這兩個洞我沒有替你填，理由見第四節——填錯的風險比留空大。

## 二、原文逐句拆解

| # | 原文 | 台灣版 | 為什麼非改不可 |
|---|---|---|---|
| 1 | 日息低至 0.01% | 總費用年百分率 [X.XX]% 起 | 台灣利率揭露的基準是 **APR（總費用年百分率）**，不是日息。只寫日息等於把開辦費、手續費藏在畫面外，屬《公平交易法》第 21 條「引人錯誤之表示」的高風險寫法；金管會對金融機構廣告招攬也要求費率揭露完整、真實 |
| 2 | 最高可借 50 萬 | 最高可貸 **NT$**50 萬 | 幣別空白。台灣預設新台幣，人民幣 50 萬和 NT$50 萬不是同一個量級，照搬就是金額不實。另外「借」改「貸」：台灣正式用語是「申貸／核貸／撥款」，「借」偏口語 |
| 3 | 秒到賬 | 核准後最快 [X] 分鐘撥款 | 「秒」是絕對化用語，實務上保證不了，是公平會處分案件的常見樣態。另外台灣標準字形是「到**帳**」不是「到賬」 |
| 4 | （缺） | 依審核結果為準＋風險警語 | 台灣消金廣告的標配。少了這兩樣，banner 做得再漂亮也是待下架狀態 |

再補三個細節：

- **「低至」** 是最低值訴求。台灣要求「最低利率」類文案同時揭露適用條件或區間，否則等於拿少數核貸案例代表全體。
- **「50 萬」要配「依審核結果」**。台灣無擔保消費貸款受 DBR22（無擔保債務餘額不得超過月收入 22 倍）約束，不是申請就有。寫「最高可貸」加免責，才站得住。
- **0.01%／日 ＝ 3.65%／年**。這個數字放到台灣消金市場偏低到不可信，比價網站一比就露餡，轉換率反而是負的。

## 三、用字對照表（給工程直接改字串用）

| 大陸寫法 | 台灣寫法 |
|---|---|
| 万 | 萬 |
| 到賬／賬戶 | 到帳／帳戶 |
| 放款 | 撥款 |
| 借款（指客戶借錢這個動作）| 申貸、核貸 |
| 秒到 | 最快 X 分鐘撥款 |
| 日息 | 年利率、總費用年百分率 |
| 手續費 | 開辦費、手續費（兩者都常見，看產品設計）|
| 個人信息 | 個人資料 |
| 身份證 | 身分證 |
| 默認 | 預設 |
| 視頻 | 影片 |

字形要走台灣標準（萬／帳／臺／裡），不要用港澳字形，也不要簡轉繁之後不校對。「臺」和「台」在台灣都可接受，但同一頁面要統一。

## 四、上線前你必須自己確認的 5 個數字

這幾個我填不了，填了就是編：

1. **總費用年百分率的區間**：下限／上限各是多少？含不含開辦費？→ 決定 `[X.XX]%` 怎麼寫
2. **台灣產品實際最高核貸額度**：是 NT$50 萬，還是人民幣額度換算後的數字？→ 決定主標金額
3. **核准到撥款的真實時間**：用實測最快值，不要用平均值；揭露頁要寫「依通路作業時間為準」→ 決定 `[X] 分鐘`
4. **放貸主體是銀行、融資公司還是媒合平台**：不是銀行的話要加「本平台非金融機構，貸款由合作機構提供」這類聲明，而且全站不能出現「銀行」「存款」等暗示受監理的詞
5. **有沒有向客戶收代辦費／服務費**：有的話 APR 算法完全不同，banner 上的數字要重算

另外提醒：台灣《民法》第 205 條約定利率上限是週年 16%，行銷文案寫「最低利率」低於這個數沒問題，但**實際核貸利率**不能超過，風控口徑要跟法務對齊。

## 五、上線檢查清單

- [ ] 所有利率以「總費用年百分率」呈現，並標明是區間
- [ ] 沒有「保證核貸」「免審核」「人人可借」「零利率」「秒到」這類絕對化用語
- [ ] 有「依審核結果為準」＋風險警語，且字級／對比度過得了法務那關
- [ ] 幣別一律 NT$，金額與落地頁、試算器完全一致
- [ ] 非銀行主體已加「非金融機構」聲明
- [ ] 個資蒐集流程有《個人資料保護法》告知事項
- [ ] 繁體走台灣字形，全站統一
- [ ] 落地頁揭露 APR、總還款金額範例、還款期限
- [ ] 法務／台灣當地律師看過（這份是行銷與合規常識層面的改寫，不等於法律意見）

## 六、還有一件事：上架審核會看這個

Google Play 對個人貸款類 App 要求提供當地合法放貸證明或與持牌機構的合作文件，App Store 對金融服務也有對應的審核條款。banner 是審核人員第一個點進去的地方——「日息 0.01%」「秒到賬」這種寫法會直接把案子拉進人工複查。先把文案改乾淨，上架會順很多。

## 七、如果只記一句

**把「日息」換成「總費用年百分率」、「秒到賬」換成「最快 X 分鐘撥款」、「50 万」加上 NT$ 和「依審核結果為準」**，其餘照抄，這版就能上。
