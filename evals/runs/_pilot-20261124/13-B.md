用的是金融 + 手機 App（zh-TW）的風格：合規硬約束優先，再疊手機端的長度限制。依據是你說「信貸 App」「上台灣」，原句本身就是一則貸款利率廣告。

## 台灣版文案

```
年利率 3.65% 起
總費用年百分率 [填：X.XX%] 起
最高可貸新臺幣 50 萬元，核准後最快 [填：__ 分鐘] 撥款

本廣告揭露之年百分率係按主管機關備查之標準計算範例予以計算，實際貸款條件仍以本行提供之產品為準，且每一客戶實際之年百分率仍視其個別貸款產品及授信條件而有所不同。實際核貸金額與利率依本行審核結果為準，撥款時間依本行作業為準。

[ 立即申貸 ]
```

## 版面

- 前兩行是同一個視覺層級，緊貼在一起。總費用年百分率是法定要揭示的，不能壓成灰色小字：「合規但看不見」不算揭示。
- 這是廣告，年百分率要跟 banner 同框，不能只放在點進去的產品頁。
- 台灣版一定比原稿長，多出來的全是法定揭露，不要為了省版位砍它。
- 數字和中文之間的空格、金額寫法（新臺幣 50 萬元／NT$500,000）全站先定一種，別 banner 一種、產品頁一種。

## 逐句

| 原稿 | 台灣版 | 問題 |
|---|---|---|
| 日息低至 0.01% | 年利率 3.65% 起 | 台灣的消費者信用交易廣告要揭示的是年化的總費用年百分率；只寫日息，等於把成本藏在一個看起來很小的數字裡。3.65% 是 0.01%×365 的單利換算，不是新報價 |
| （缺） | 總費用年百分率 [填：X.XX%] 起 | 《銀行業暨保險業辦理消費者信用交易廣告應揭示總費用範圍及年百分率計算方式標準》第 2、8 條：消費性貸款廣告要揭示總費用年百分率，四捨五入到小數第二位。只寫「年利率 X% 起」不合規 |
| 最高可借 50 万 | 最高可貸新臺幣 50 萬元 | 貸款語境用「貸」不用「借」；幣別要標，原稿的 50 萬是人民幣口徑 |
| 秒到账 | 核准後最快 [填：__ 分鐘] 撥款 | 「秒到帳」把時效說成絕對值，讀起來還像「申請就到、一定核得過」，《金融消費者保護法》第 8 條不認這種引人誤信。加「核准後」把範圍收窄，時效換成可核對的數字 |
| ！ | 刪 | 金額、利率旁邊不用感嘆號 |

## 新增的事實與出處

| 事實 | 出處 |
|---|---|
| 年利率 3.65% | 原稿「日息 0.01%」× 365（單利） |
| 新臺幣 50 萬元 | 原稿「50 万」；幣別要在台灣版重新確認（見第 3 條） |
| 總費用年百分率 X.XX% | 沒有出處：要含開辦費等全部費用、按期數算，由產品端／法遵給 |
| 撥款時效 | 沒有出處：原稿「秒到账」沒有口徑，由產品端給實測值 |
| 免責句 | 金管會 94.11.30 金管銀（三）字第0940030381號函准予備查的計算範例說明句；我手上是技能檔記載的大意，逐字要對原文 |

## 要補的、要確認的

1. **總費用年百分率**：不能拿 3.65% 頂。它含開辦費等費用，不會比年利率低，要按信貸類的標準計算範例（借款金額、期數）算，寫到小數第二位。不同期數或費用方案的年百分率不同時，這裡要寫區間（X.XX%～Y.YY%）。
2. **撥款時效**：原稿「秒到账」是什麼口徑？確認後填「即時」、「10 分鐘」或「當日」。拿不出可核對的數字，就把「核准後最快…撥款」整段刪掉，免責句裡「撥款時間依本行作業為準」也一起刪；別留一個說不出數字的「快」。
3. **額度幣別**：原稿 50 萬是人民幣。台灣版是新臺幣 50 萬元，還是重新定價？直接沿用等於改了一個事實，要產品端點頭。
4. **「本行」是誰**：免責句寫「本行」。如果營運主體是融資公司不是銀行，要改成公司自稱，適用規範也不同。
5. **免責句逐字**：上面那句是範例大意，上線前用備查的計算範例原文逐字對一遍。
6. **警語**：「謹慎理財，信用至上」是信用卡、現金卡廣告的法定警語，信貸不是必須。公司內部規範若要求消費金融廣告統一掛，就加在免責小字最前面。
7. **按鈕去向**：點下去如果是額度試算不是送件，「立即申貸」要改成「立即試算」。

## 刻意沒改、刻意拿掉

- 三個賣點都留著：利率、額度、快。改的是「日息→年利率」、「秒→核准後＋可核對的時效」、「借→貸」。
- 沒保留日息：法規上日息可以跟年率並列，但 banner 上日息一定比年率好讀，留著等於自己把視覺焦點拉回小數字。產品若堅持要，日息的字級不能大於年利率和年百分率。
- 沒加「貸款有風險」一類的話：台灣的信貸廣告沒有這條法定警語，加了只佔版位。法遵要就加。
- 沒在 banner 上多塞括號：審核條件收進免責句，不在額度後面掛「（依審核結果）」再重複一次。

## 版位不夠時的縮版

必須留：年利率、總費用年百分率、免責小字。可砍：額度、撥款時效。

```
年利率 3.65% 起
總費用年百分率 [填：X.XX%] 起

[免責小字原樣]
```

砍賣點可以，砍揭露不行。
