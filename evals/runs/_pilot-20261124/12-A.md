**三句台湾版（zh-TW）**

① 上傳檔案失敗，請檢查網路後重試。
② 預設儲存到「我的文件」資料夾。
③ 此影片暫不支援在行動裝置上播放。

**这几处是换词，不是转字**

| 简体 | 台湾写法 | 原因 |
|---|---|---|
| 上传文件 | 上傳檔案 | 「文件」在台湾指 document，file 是「檔案」 |
| 我的文档 | 我的文件 | document 才是「文件」；简体的「文件」和繁体的「文件」不是同一个东西 |
| 文件夹 | 資料夾 | |
| 默认 | 預設 | 台湾不用「默認」 |
| 保存 | 儲存 | |
| 网络 | 網路 | 香港才是「網絡」 |
| 视频 | 影片 | |
| 支持（功能、格式） | 支援 | |
| 移动端 | 行動裝置 | |

最容易翻车的是 ① 和 ② 撞在一起：① 的「文件」是 file，转成「檔案」；② 的「文档」是 document，转成「文件」。直接跑 OpenCC 会把两句都变成「文件」，字对了词全错。

**刻意没改的**

- 三句的句号、句子结构、「請」只出现一次、报错仍是「问题 + 下一步」；「重試」本来就是台湾界面在用的词，不改成「再試一次」。
- 没加「多次失敗請聯繫管理員」：原句没这个承诺，加不加是客服口径的事，不替产品编。
- 字数：① 与原文相同，② 相同，③ 多 1 字（「行動裝置」比「移动端」长一字），不会撑破版面。

**要你确认的 2 处**

1. ② 的文件夹名（这句里我唯一拿不准的地方）：如果指系统文档文件夹，名字得跟台湾用户机器上实际看到的一致（Windows 10/11 和 macOS 台湾版显示为「文件」，更早的 Windows 是「我的文件」）；如果是 App 自建的文件夹，就用 App 自己定好的名字。我按原句直译成「我的文件」，名字最终以实际显示为准，否则提示会把用户指到一个叫不出这个名字的地方去。
2. ③ 的「在行動裝置上播放」：这句如果只出现在手机 App 里，读者手上就是手机，写「在手機上播放」更直接；如果手机、平板、网页共用同一份文案，保留「行動裝置」。另外「此影片」写成「該影片」台湾也读得通，但两种只用一种，全站别一处「此」一处「該」。

**顺带三句**

- ① 如果现在是 toast：带「請檢查網路後重試」这种下一步的报错不该只弹 toast（自动消失，用户来不及看），走 dialog 或页内提示。
- 如果这三句被测试按文案定位，替换时一起改锚（先 grep 旧句子）；没给仓库，`check_copy_anchors.py` 跑不了。
- 香港版不能直接套这三句：網路要写「網絡」，行動裝置要写「流動裝置」。

行业风格用的是手机 App（mobile），依据：你说「我们 App」，句子里有「移动端」「视频播放」；繁体按 `locale-zh-hant.md` 的台湾列和 `mobile.md` 第 11 节台港差异过了一遍，项目没有繁体术语表，系统类词以 Microsoft zh-TW 为准（檔案、資料夾、預設、儲存、網路、支援、行動裝置）。
