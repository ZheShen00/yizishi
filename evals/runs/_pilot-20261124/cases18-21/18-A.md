# 设置页文案问题清单

判据：按 system（系统 / 桌面客户端）风格审，依据是「设置页」加上「剩余空间 / 本地缓存 / 同步失败」这类桌面客户端词。如果这实际是给开发者用的控制台，「沙箱」「引擎」「快照」那几条降为「需要确认」。

位置按你贴的顺序记（第 1–6 条）；没给仓库，定位只到条目。渲染面按纯文本标签算。

## 逐条

**1.「剩余空间不足 200 字节」（第 1 条）**

- 类别：内部计量 + 缺动作 + 歧义
- 问题：「字节」是内部计量，200 字节用户读不出是多少，也据此做不了任何事，这个数字像是把内部字节数直接拼进句子、没做单位换算。整句没说是哪个空间，也没给下一步。「不足 200 字节」还有两种读法：少于 200，还是只剩 200。桌面系统的存储警告要求给可读的可用空间和明确动作。
- 几个字的改法：「剩余空间」→「可用存储空间」；「200 字节」→「[填：按 MB / GB 显示的可用空间]」；句尾补一步动作（清理缓存 / 卸载不用的应用）。

**2.「快照保留 7 天」（第 2 条）**

- 类别：开发者用词 + 缺后果
- 问题：「快照」是内部叫法。只说了 7 天，没说从哪天算、到期会怎样（自动删除？还能不能找回），用户拿这条判断不了该不该自己备份。
- 几个字的改法：「快照」按它实际指的东西换成「历史版本」（文档版本）或「备份」（整机 / 数据备份）；到期后果要产品给，缺的写 [填：到期后删除 / 可否恢复]。

**3.「沙箱环境仅供测试」（第 3 条）**

- 类别：用户看不见的机制
- 问题：「沙箱」「环境」都在讲系统怎么隔离，用户看不见也做不了；「仅供测试」还有两种读法（只准拿来测试，还是我们内部测试用）。用户要知道的是：这里的数据和正式数据分不分、会不会被清空。
- 几个字的改法：「沙箱环境」→ 产品里已有的入口名（如「测试空间」）；「仅供测试」后补一句数据后果 [填：测试数据会不会清空]。

**4.「引擎版本 v2.3」（第 4 条）**

- 类别：开发者用词 + 版本号格式
- 问题：「引擎」是内部组件名，用户不知道这是谁的版本，也没法用它做事。版本号本来是报障时用的，要写清是应用、模型还是同步服务的版本。小写 v 是开发写法。
- 几个字的改法：「引擎」→「[填：应用 / 模型 / 同步服务]」；「v2.3」→「2.3」，同一页版本号只用一种格式。

**5.「操作留痕可在后台查看」（第 5 条）**

- 类别：开发者用词 + 空主语 + 缺入口
- 问题：「留痕」「后台」都是内部说法；「可在后台查看」是谁看、从哪儿进都没说，用户照着这句找不到入口。界面文案要写用户在界面上真能看到的菜单名。
- 几个字的改法：「操作留痕」→「操作记录」；「后台」→「[填：如「设置 > 操作记录」]」。

**6.「同步失败后会先回落本地缓存，再补传」（第 6 条）**

- 类别：整句讲机制
- 问题：「回落」「缓存」「补传」三个内部词，整句说的是内部流程。用户要的结果只有三件：东西还在不在、会不会丢、要不要我做什么。设置项的说明该写「开启后会怎样」，不写失败时内部怎么走。
- 几个字的改法：留结论、删流程，事实由产品补：「先回落本地缓存，再补传」→「[填：内容已保存在本地，联网后自动同步 / 需要手动重试]」。

## 全组的问题（逐句改字救不了）

1. **结构混了两种元素**：第 1、2、4 条是信息行（数值 / 版本），第 3、5、6 条是说明句。先定每条是「设置项标签 + 说明」还是「关于页的一行信息」，再定句式和位置；不然词改完了，主次和排版还是乱的。
2. **六条都没写对象**：谁的空间、谁的快照、哪个引擎、谁的操作、哪次同步。有的靠上下文能省，第 1、6 条省掉就看不出在说哪个功能。
3. **叫法要先统一**：存储空间、历史版本、操作记录。另外第 2 条的「快照」和第 6 条的「本地缓存」是不是同一批数据要确认，是的话不能两个叫法。项目里还没有术语表的话，建议起一份，把这三个词和各自不用的写法写进去。

## 需要确认 / 待核

- 三处数字（200 字节、7 天、2.3）要和代码里的值对一遍。没给仓库，核不了，全部待核。
- 第 2 条的快照是文档版本还是整机备份，决定叫「历史版本」还是「备份」；到期后是否自动删除、能否找回。
- 「沙箱」「引擎」「快照」如果是产品定过的功能专名（面向开发者，或被门禁锚着），按「需要裁决」处理，不擅自换。
- 同步失败后的真实行为：自动重试还是手动、本地副本留多久。
- 测试环境的数据会不会被清空。
- 操作记录在界面上的入口名。
- 没给仓库和测试，查不了锚：第 3、4、5 条若被测试锚着，改名要和测试一起改。

## 不用改的

六条都不带句号（标签和单独一行提示的正确写法），数字与中文之间有空格，没有 `**`、破折号、感叹号这类残留。这几项没问题。
