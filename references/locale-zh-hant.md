# 繁体界面：用词和标点

界面是 zh-TW（台湾）或 zh-HK（香港）时读这份。简体转繁体只换字不换词，台湾用户一眼就看出是「大陆翻过来的」。

## 怎么用

1. 先看项目有没有自己的繁体术语表；有就以它为准。
2. 没有的话，系统和软件类词以 Microsoft 的 zh-TW / zh-HK 术语为准（Windows、Office 的界面用词就是用户最熟的那套），其余按下表。
3. 简繁转换工具（OpenCC 的 `s2twp` 会顺带换词）可以先跑一遍，再人工核下表里的词；工具换不了按语境判断的词。

## 按语境判断的词

- **信息**：information 写「資訊」，一条消息写「訊息」。
- **文件**：先确定简体原文指 file 还是 document，再选「檔案」或「文件」。
- **发布**：台湾两种都见到（「發布」「發佈」），全站选一种写进术语表。
- **视频**：台湾写「影片」；但「視訊」专指实时通话、摄像头。
- **网友、小伙伴、宝藏**：大陆网络口吻，界面上改「使用者」「大家」或直接删。

## 标点

- 全角标点；引号先用「」，引号里再套用『』。
- 中文与英文、中文与数字之间加空格的约定和简体一样，按项目统一。
- 台湾的书面删节号是「……」（两个省略号）；界面里截断文字用单个「…」可以，全站一种。
- 中文句子里不混半角逗号、半角冒号。

## zh-HK 的差异

香港和台湾用词不完全一样，不要拿 zh-TW 直接充当 zh-HK：

- 香港界面常见「用戶」「軟件」「網絡」「設定」「登入」等，部分和大陆接近、部分和台湾接近。
- 以 Microsoft zh-HK 术语和项目自己的术语表为准；拿不准就问用户目标市场。

## 不要换的

- 产品名、品牌名、平台专名照原文（「小紅書」不改成别的说法）。
- 引用的用户原话、法规原文、合同条款，一字不改。
- 代码、键名、API 字段、命令。
- 用户在术语表里定过的词，即使和上表不同。
