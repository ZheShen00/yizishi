## 1. 什么时候用这份

信号（命中任意两条就用；只命中一条时，结合用户的话判断）：

- 代码 / 依赖：`lti`（LTI 协议）、`scorm`（SCORM 课件包）、`xapi` / `tincan`、`h5p`、`moodle`、`canvas-lms`、`openedx` / `edx-platform`、`respondus`、`proctorio`、`turnitin`、`gradescope`
- 目录 / 文件名：`courses/`、`assignments/`、`quizzes/`、`exams/`、`grades/`、`gradebook/`、`enrollments/`、`submissions/`、`classrooms/`、`lessons/`、`cohorts/`
- 界面里的词：课程、作业、测验、考试、提交、交卷、批改、评分、成绩、学分、打卡、连续学习、错题本、正确率、及格线、补交、缓考、监考、防作弊、未成年人模式、家长端、学生端、教师端、知识点、学号、班级
- 用户的话：「在线课堂」「网课」「LMS 系统」「刷题」「家校沟通」「学习机」「在线教育平台」「智慧教育」

和别的行业重叠时：

- **教育 + 支付**（课程购买、会员续费、退款）：先按金融行业的合规硬约束（价格展示准确、退款条款清楚、自动续费提前告知），再叠本文件关于未成年人账户和「双减」广告用语的规则。
- **教育 + AI**（AI 外教、AI 批改、学情分析）：先按本文件的硬约束（AI 身份披露、不制造焦虑、不对未成年人做画像推送），AI 相关的通用规则（模型说错了要可撤回）作为补充。
- **教育 + 医疗**（特殊教育、心理测评类工具）：按医疗行业的隐私和诊断类用语约束优先，本文件补充未成年人部分。

## 2. 语气和人格

一句话定调：**说清楚学到了什么、还差什么、下一步做什么，鼓励但不代替评判，绝不羞辱。**

这个行业比大多数行业更依赖「对谁说话」：同一产品里学生、家长、教师三种身份看到的文案，语气必须分开写，不能用一套话术套三种人。

- **人称**：对学生（尤其未成年）用「你」；对家长、教师用「您」。同一条消息可能要分两份文案分别推给家长和孩子，不能共用一份。
- **正式程度，按受众分**：
  - 面向儿童 / 低龄学生（K12 以下）：短句、具体动词、不绕弯子；可以用适度感叹号表达鼓励（「又进步啦！」），但同一类提示一天内别反复堆砌感叹号，堆多了显得廉价。
  - 面向成人学习者（职业教育、MOOC）：专业、平实，不用可爱化表达；Coursera / edX 式的直接陈述（「你已完成第 3 周内容」），不用儿童向的拟人插画腔。
  - 面向家长：事实陈述优先，不评判、不比较；哪怕是坏消息（孩子多次迟交），也只说事实和可选的下一步，不下结论性评价（不写「孩子不够自律」）。
  - 面向教师 / 管理员：信息密度可以更高，允许术语（学情、知识点掌握度、及格率），不需要鼓励式语气。
- **能不能幽默**：对成人学习者可以有克制的幽默（吉祥物式的玩笑），涉及成绩、考试、违纪调查的场景一律不能幽默。
- **和 `references/principles.md` 不同、要覆盖它的地方**：
  - 通用规则建议「全站一种人称」；教育类产品按身份分人称是例外，必须在术语表里写清楚哪些界面对谁用「你」、哪些用「您」。
  - 通用规则的「不卖萌」对成人学习者成立，但面向低龄学生，适度拟人（吉祥物、表情）是这个行业的惯例，不算卖萌，只要不被用来制造愧疚或攀比。
  - 通用规则「关键信息放前面」在家长报告里照样适用，但放在前面的是具体事实（「本周有 2 次作业迟交」），不是结论性评价（「孩子退步了」），并且紧跟一个可行建议，不能只甩一个负面结论在开头。

**三种受众对照**（同一件事，三份文案）：

| 场景 | 对学生（儿童 / 青少年） | 对家长 | 对教师 |
|---|---|---|---|
| 一次测验答错较多 | 这几道题还不太熟，我们再练一次 | 孩子本周有 3 道分式方程题答错，可以一起看看错题本 | 本班分式方程正确率 62%，低于年级均值 |
| 连续多天没打卡 | 3 天没打卡了，今天花 5 分钟接上吧 | 孩子最近 3 天没有学习记录 | （一般不单独提示教师，除非需要班级层面干预） |
| 作业迟交 | 这次作业晚交了，不影响重新开始 | 孩子这次作业迟交了 1 次 | 该生本周有 1 次迟交，已超过提醒阈值 |

成人学习者（Coursera / edX 式场景）没有「家长 / 教师」两端，只有学习者本人和（偶尔）企业管理员；企业管理员看的是完成率和认证进度，不需要鼓励式语气，按上表「教师」一栏的直接陈述处理即可。

## 4. 术语和叫法

| 用 | 不用 | 说明 |
|---|---|---|
| 提交作业 | 交作业、上交作业 | 正式场景统一用「提交」；面向低龄学生的按钮可以用更短的「交作业」 |
| 未提交 | 没写、没交 | 不带评判色彩的状态词，避免「没写」暗示态度问题 |
| 缺交 | 漏交 | 「缺交」指过了截止时间仍未提交，和「未提交」（还在截止前）区分开 |
| 迟交 | 逾期提交、过期提交 | 全站固定叫法，和「缺交」是两个不同状态（迟交＝晚交了但交了） |
| 批改中 | 批阅中、阅卷中 | 全站一个叫法；「阅卷」更适合大型统考场景，日常作业统一用「批改」 |
| 已批改 | 已改完、老师看过了 | 面向学生 / 家长的正式状态词 |
| 退回重做 | 打回、退回 | 加「重做」说明学生接下来要做什么，不只给一个状态词 |
| 得分 | 成绩（低龄学生界面） | 面向儿童优先用「得分」，弱化评判感；面向家长、教师的报告用「成绩」 |
| 正确率 | 对题率、准确率 | 全站统一一个说法，「准确率」更像系统指标，不用在学生可见文案里 |
| 及格线 | 合格线、通过线 | 同一产品统一一个叫法；职业资格类课程可用「通过线」 |
| 连续学习天数 | 连胜、streak（中文界面） | 英文界面可保留 streak；中文界面避免生造的游戏化词，直接说「连续学习 X 天」 |
| 学习时长 | 在线时长、使用时长 | 「使用时长」是系统统计口径，面向家长应说「学习时长」，除非确实包含非学习内容 |
| 知识点 | 考点 | K12 场景统一「知识点」；考证、职业资格类课程可用「考点」 |
| 错题本 | 错题集、错题库 | 全站一个叫法 |
| 学号 | 账号 | 学号是学籍标识，账号是登录凭证，两者不是一回事，不能混用 |
| 班级 | 班级群 | 「班级」是教学实体，「班级群」特指聊天群功能，别处出现时要单独说明 |
| 监护人 | 家长（法律声明、隐私条款场景） | 法律文本和同意书用「监护人」，与法规术语对齐；日常界面可用更亲切的「家长」 |
| 未成年人模式 | 青少年模式（新写的文案） | 《未成年人网络保护条例》统一用「未成年人模式」；项目里历史上用「青少年模式」且已经过用户验证的，按项目术语表为准，不擅自改 |
| 教师端 | 老师端 | 产品身份入口统一「教师端」，口语沟通里可以说「老师」 |
| 学生端 | 孩子端 | 产品身份入口统一「学生端」；面向家长的沟通文案里可以说「孩子」 |
| 开课时间 | 上课时间（指课程整体开放时间时） | 「上课时间」特指直播 / 教室场景的具体时段，「开课时间」指课程对外开放的起始日期，混用会让人分不清是约好的直播还是随时能学 |
| 考试时长 | 答题时长 | 考试时长包含阅读说明等全部环节；「答题时长」特指倒计时内可答题的时间，限时考试里两个数字可能不同，不能混用 |
| 续报 | 续费（课程场景） | 课程重新报名用「续报」，订阅会员用「续费」，两个计费逻辑不同 |
| 打卡 | 签到（自主学习场景） | 「打卡」是学生自主记录学习习惯；「签到」是课堂 / 直播点名确认出勤，对应不同功能不能混用 |
| 补交 | 补交作业、晚交 | 指教师手动开放后的二次提交窗口，和系统自动判定的「迟交」是两回事 |
| 缓考 | 延期考试 | 考务场景的固定叫法，涉及审批流程，不用更随意的「延期考试」代替 |
| 监考 | 考试监督 | 固定叫法，含人工监考和 AI 监考两种，具体哪种要在旁边说明，不能只写「监考中」 |
| 直播课 | 在线课堂（指实时授课时） | 「在线课堂」容易和随时可看的录播课混淆，实时授课统一叫「直播课」 |
| 录播课 | 点播课、回放课 | 全站一个叫法；「回放」专指直播结束后生成的那一份，录播课可以是一开始就按录播形式上线的 |
| 课程证书 | 结业证书（和「专业方向证书」混用时） | Coursera / edX 式产品里「课程证书」（单门课）和「专业方向证书」（一组课程）是两个不同产品，不能互换 |
| 认证考试 | 资格考试（面向职业教育时） | 同一产品里统一一个叫法，避免学生搞不清是不是同一场考试 |

## 5. 按元素写

只写和通用写法不同的地方，通用规则见 `references/principles.md`。

**按钮**

- 作业 / 考试提交相关的不可逆按钮，第二次确认要写清楚动作本身，不写「确定」：
  - 中：仍要交卷 / 确认提交
  - 英：Submit anyway / Confirm submission（not "OK"）
- 面向低龄学生的主操作按钮用更短的动词：开始、交卷、再试、下一题。

**表单标签和校验**

- 学号、准考证号这类格式固定的字段，校验失败要给格式示例，不写「格式错误」：
  - 中：学号应为 8 位数字，例如 20230145
  - 英：Student ID should be 8 digits, e.g. 20230145
- 涉及未成年人的注册信息（出生日期用于判断是否需要监护人同意）校验未通过时，不对学生本人显示判断性结论，只提示下一步：
  - 不写：你未满 14 周岁，不能自己注册
  - 改写：需要监护人完成下一步，才能继续注册

**报错**

- 考试 / 作业提交失败要先区分「可重试」和「时间已到自动收卷」，不能用一句话糊弄：
  - 可重试：提交失败，请重试；多次失败请联系监考老师。
  - 时间到自动收卷：已到交卷时间，系统已自动提交当前作答，不会丢失已完成的题目。
- 报错里不写「丢分」「不及格」这类带评判的推断，只写系统确认了的事实。

**空状态**

- 错题本、待批改列表为空时，不用「太棒了一道错题都没有」这类读起来像廉价表扬的话，改成平实陈述加下一步：
  - 中：这里还没有错题。继续做题，答错的题会自动收进来。
  - 英：No mistakes here yet. Answers you get wrong will show up here automatically.

**确认框**

- 作业 / 考试提交前的确认框必须同时包含：交卷后能不能改、剩余时间、未完成题数：
  - 中：还有 3 题未作答，提交后无法修改。确认交卷吗？
  - 英：3 questions unanswered. You can't change your answers after submitting. Submit anyway?

**状态标签**

- 固定一套闭合状态词，不能互相替代：未提交 / 已提交 / 迟交 / 缺交 / 批改中 / 已批改 / 已退回。
- 监考 / 防作弊结果的状态不能用听起来像完成的词表示「存疑」：确认中 / 需复核 / 已确认，不能把「需复核」写成「已通过」。

**通知 / 推送**

- 禁止制造攀比或愧疚的措辞，这是这个行业和别的行业区别最大的地方：
  - 不写：你的好友已经超过你了，快去学习吧
  - 不写：Duo 很伤心，你已经 3 天没来学习了（仿 Duolingo 被报道过的 "You made Duo sad" 一类提醒，见第 3 节）
  - 改写：你已经 3 天没打卡了，今天花 5 分钟接上吧
- 给家长的通知只陈述事实加可选操作，不做评价性总结：
  - 不写：孩子本周表现不理想
  - 改写：孩子本周有 2 次作业迟交、1 次未交。查看详情

**进度、等待**

- 批改 / 阅卷中的等待文案给大概时间，不用「精心批改」这类自夸式修饰：
  - 中：老师正在批改，预计 1-2 个工作日内出分
  - 英：Your teacher is grading this now — results in 1–2 business days

**引导、首次使用**

- 面向儿童的首次引导一步一个动作，配图标，不写大段说明；面向教师 / 管理员的引导可以展开讲后台概念（年级、班级、知识点体系的关系）。

**帮助说明**

- 监考 / 防作弊说明必须列出被监控的具体内容（摄像头画面、屏幕录制、人脸比对、浏览器行为），不能用「全程监考」一句话带过。

## 6. 合规和硬约束

### 未成年人网络使用和个人信息

- 《中华人民共和国未成年人保护法》（2020 修订，2021 年 6 月 1 日施行）第五章「网络保护」要求网络产品和服务提供者对未成年人使用场景承担特别义务；其中第七十四条明确网络游戏、网络直播、网络音视频、网络社交等服务提供者应当针对未成年人使用其服务设置相应的时间管理、权限管理、消费管理等功能，教育类产品只要带社交、打赏、直播课功能就适用。全文（最高人民检察院转载）：<https://www.spp.gov.cn/spp/fl/202010/t20201018_482257.shtml>
- 《中华人民共和国个人信息保护法》第 28 条把「不满十四周岁未成年人的个人信息」列为敏感个人信息，第 31 条要求处理不满十四周岁未成年人个人信息必须取得父母或其他监护人同意，并制定专门的未成年人个人信息处理规则。落到文案：面向可能涉及不满 14 周岁用户的注册、授权、隐私同意页面，必须有监护人同意的步骤和明确告知，不能只给学生本人一个「同意」按钮。来源：<https://www.gov.cn/xinwen/2021-08/20/content_5632486.htm>
- 《未成年人网络保护条例》（国务院令第 766 号，2024 年 1 月 1 日起施行）第四十三条要求网络产品和服务提供者设置「未成年人模式」，在使用时段、时长、功能和内容等方面按规定提供服务，并为监护人提供时间管理、权限管理、消费管理功能；第四十四条要求合理限制不同年龄阶段未成年人的单次和单日累计消费数额。「未成年人模式」是条例确立的统一制度名称，教育类 App 的青少年保护功能文案应对齐这个名称，不要自造「少儿模式」「儿童模式」等近义词。来源：<https://www.gov.cn/zhengce/content/202310/content_6911288.htm>
- 三份规定叠加的结果：产品里只要有「未成年人模式」开关，文案要说清楚限制的是什么（时长、功能、消费）、怎么解除（通常需要监护人操作），不能只写「已开启未成年人模式」一句话。
- 国家网信办《移动互联网未成年人模式建设指南》（2024-11-15 发布，正式版）给了终端层的默认值：不满 16 周岁"默认推荐使用总时长不超过1小时"、16 至 18 周岁不超过 2 小时，连续使用超过 30 分钟发出休息提醒，"每日22时至次日6时期间默认不向未成年人提供服务"，都允许家长豁免；"退出未成年人模式，需要家长进行验证同意"。教育类产品要注意豁免条款：「在有关主管部门备案的，为未成年人提供网课等教育服务的产品和服务」不受上述时长和时段限制。落到文案：自己加的时段限制（如第 7 节例子里的 21:00）要写明是产品或家长设置的，不要写成法定时段；退出入口的说明写清「需要家长验证」。来源：<https://www.cac.gov.cn/2024-11/15/c_1733364304749288.htm>
- 教育部基础教育教学指导委员会《中小学生成式人工智能使用指南（2025年版）》（2025-05 发布）："小学阶段禁止学生独自使用开放式内容生成功能，教师可在课内适当使用辅助教学"；教师"禁止直接使用AI回答学生问题或提供咨询；应避免直接使用AI生成内容评价学生"；学生"应避免在作业中简单复制生成式人工智能工具生成的内容"。落到文案：面向小学生的 AI 对话 / 生成入口要写清需要老师或家长在场，不能写成学生自己随便问；AI 批改、AI 评语要标明是 AI 生成、由老师确认。指南由教指委发布，教育部官网只有新闻稿，全文见《人民教育》首发、北京日报转载：<https://xinwen.bjd.com.cn/content/s68217324e4b0ec1c3d96f32d.html>；发布新闻：<https://www.gov.cn/lianbo/bumen/202505/content_7023810.htm>

### 备案与资质

- 教育部办公厅《教育移动互联网应用程序备案管理办法》（教技厅〔2019〕3 号，2019 年 11 月印发）第十四条规定：备案信息通过国家数字教育资源公共服务体系向社会公布，提供者应在教育移动应用中公示备案信息以便用户查询（原文没有进一步规定具体展示位置或格式）。落到文案：备案编号展示页（通常是「关于我们」或登录页底部）给出固定格式的编号展示、不要藏进二级菜单——这是基于「公示以便查询」原则的文案建议，不是条文逐字规定的位置。来源：<http://www.moe.gov.cn/srcsite/A16/s3342/201911/t20191122_409333.html>

### 广告和营销用语

- 中共中央办公厅、国务院办公厅《关于进一步减轻义务教育阶段学生作业负担和校外培训负担的意见》（2021 年 7 月，「双减」）明确「各类新闻媒体、网站、新媒体等不得刊登发布校外培训广告」。面向义务教育阶段（小学、初中）学生的培训类产品，公开营销文案要避开会被认定为校外培训广告的表述，站内文案也要避免制造「不学就落后」的焦虑感。来源：<https://www.gov.cn/zhengce/2021-07/24/content_5627132.htm>
- 《中华人民共和国广告法》第 38 条限制不满十周岁的未成年人作为广告代言人，教育类产品如果用「小学霸」「满分学员」做真人代言或推荐语，要避开未满 10 周岁的孩子出镜代言（条号建议核对《广告法》现行修正版原文）。来源：<https://www.gov.cn/>
- 《中华人民共和国广告法》第二十四条规定教育、培训广告不得对升学、通过考试、获得学位学历或者合格证书、提高学习成绩等作出明示或暗示的保证性承诺，不得明示或暗示有考试命题人员参与，不得利用专业人士或受益者名义作推荐证明——「名师押题」「保过」「提分 30 分」「通过率 100%」这类用语都落在禁止范围内。市场监管总局 2021 年 4 月起开展「呵护青少年健康成长」教育培训类广告专项整治，同年 11 月市场监管总局等八部门另发《关于做好校外培训广告管控的通知》（国市监广发〔2021〕70 号）限制校外培训广告的发布渠道；此前本节标注的《关于进一步规范教育培训广告的通知》（2021 年 4 月）未能找到对应原文，予以更正，改引以上两份可查证的依据。落到文案：课程详情页、营销落地页不写「保过」「这次不学就晚了」一类话术。来源：<https://www.gov.cn/>（广告法）；<https://gkml.samr.gov.cn/nsjg/ggjgs/202111/t20211109_336575.html>（校外培训广告管控通知）

### 国际：COPPA / FERPA / UK AADC / WCAG

- 美国 COPPA（儿童在线隐私保护规则，16 CFR Part 312）要求收集不满 13 岁儿童的个人信息前，必须先向家长发送直接通知（16 CFR § 312.4）并取得可验证的家长同意（16 CFR § 312.5）。落到文案：面向美区、13 岁以下用户的注册流程，必须有单独给家长看的通知页，不能让孩子本人点一个同意按钮就跳过。来源：<https://www.ftc.gov/legal-library/browse/rules/childrens-online-privacy-protection-rule-coppa>
- 美国 FERPA（家庭教育权利和隐私法，20 U.S.C. § 1232g；34 CFR Part 99）规定学生满 18 岁或进入高等教育阶段后，查看和控制自己成绩记录的权利从家长转移给学生本人（「eligible student」）。原文 34 CFR § 99.3："Eligible student means a student who has reached 18 years of age or is attending an institution of postsecondary education."；§ 99.5(a)(1)："When a student becomes an eligible student, the rights accorded to, and consent required of, parents under this part transfer from the parents to the student."；§ 99.5(a)(2) 留了例外，如学生是家长报税时的受抚养人（§ 99.31(a)(8)），学校可以不经学生同意向家长披露。落到文案：面向美区高等教育场景的产品，家长端如果还保留查看成绩的入口，要先判断学生是否已经是「eligible student」，不能默认家长一直能看到成绩；同意 / 授权弹窗要发给学生本人，不是家长。来源：<https://www.ecfr.gov/current/title-34/subtitle-A/part-99>（eCFR 现行文本，2026-10 核对）；<https://studentprivacy.ed.gov/>
- 英国 ICO《适龄设计准则》（Age Appropriate Design Code / Children's code）共 15 条标准，其中标准 4「透明度」（Transparency）要求隐私说明用孩子能看懂的语言重新写一遍，不能只放一份面向成年人的隐私政策；标准 5「数据有害利用」（Detrimental use of data）和标准 13「推动式设计」（Nudge techniques）明确反对用诱导式设计让孩子交出更多数据或关闭隐私保护。落到文案：面向英区未成年用户的隐私说明要有专门的「写给孩子看」的版本，不能和成人版共用一份。来源：<https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/childrens-information/childrens-code-guidance-and-resources/>
- WCAG 2.1 成功标准 3.1.5（Reading Level，AAA 级）要求正文在去掉专有名词后，阅读难度不超过初中（lower secondary education）水平，超过的要提供简化版本或补充说明。原文：「When text requires reading ability more advanced than the lower secondary education level after removal of proper names and titles, supplemental content, or a version that does not require reading ability more advanced than the lower secondary education level, is available.」 落到文案：面向 K12 学生的正文说明按这个标准控制句子长度和用词难度。来源：<https://www.w3.org/WAI/WCAG21/Understanding/reading-level.html>

### 拼音 / 生僻字和低龄可读性

- 面向小学低年级（认读汉字量有限）的界面文案，生僻字、容易读错的多音字要配拼音或换成更常见的字，这不是法规要求，是行业惯例——不同版本教材（人教版、统编版等）的常用字表并不完全一致，不存在单一、可逐字核对的「标准字表」，写文案时按项目实际面向的教材版本或年级识字量估算即可，不必追求对应到某一份具体字表。
- 按钮、标签的字数尽量落在学生识字量范围内，优先用课本常见词，不用「鉴于」「综上」「即可」这类书面语连接词。

## 7. 高风险场景

### 考试 / 作业截止与不可逆提交

必写要素：剩余时间、未完成题数、提交后能不能改、网络问题要不要自动保存。

- 中：还剩 2 分钟，已自动保存到第 8 题。时间到会自动提交当前作答。
- 英：2 minutes left. Your answers up to question 8 are saved. We'll auto-submit when time runs out.

### 防作弊 / 监考通知

必写要素：被监控的具体内容（摄像头 / 录屏 / 人脸比对 / 浏览器行为）、监控的使用目的、退出会发生什么。

- 中：本场考试会录制摄像头画面和屏幕操作，仅用于本次考试的违规复核，考试结束后按学校规定的期限保存。退出考试页面会被记为异常。
- 英：This exam records your camera and screen activity for integrity review only, kept for the period your institution specifies. Leaving this page is logged as a flagged event.

不能只写「本场考试已开启监考」，监考范围和用途必须摆在明处。

### 未成年人模式时间限制

必写要素：限制的具体内容（时长 / 时段 / 功能）、谁能解除、现在还能做什么。

- 中：未成年人模式下，每天 21:00 后无法继续做题，需要监护人解除。今天还可以学习 20 分钟。
- 英：In Under-18 Mode, practice is paused after 9 PM. A parent or guardian can turn this off. You have 20 minutes left today.

不写单纯一句「时间已到，请明天再来」，没说清楚谁能解除、是不是每天都这样。

### 成绩 / 个人信息可见范围

必写要素：这条信息谁能看到（本人 / 监护人 / 教师 / 同学），改变可见范围前要不要额外确认。

- 中：这份成绩单只有你和授课老师能看到，同学看不到具体分数。
- 英：Only you and your teacher can see this grade — classmates can't.

涉及「把成绩或排名公开给全班」这类操作，必须单独确认，不能作为默认设置。

### 违纪 / 作弊调查结果通知

必写要素：调查结论、依据的规则条款或证据类别、申诉渠道和期限；语气正式、不羞辱。

- 中：系统在本次考试中检测到异常行为，依据《考试管理规定》第 X 条，本次成绩被标记为「待复核」。如有异议，可在 7 天内提交申诉。
- 英：This exam was flagged for a possible integrity issue under Exam Policy Section X. The score is marked "under review." You can appeal within 7 days.

不写「你作弊了」这种定性结论在系统自动判定阶段就下达；自动判定只能说「异常 / 待复核」，人工复核确认后才能用更明确的结论性措辞，并且要给申诉渠道。

### 自动续费 / 课程购买（未成年人账户）

必写要素：扣款金额、扣款时间、谁能取消、是不是用了监护人的支付方式。

- 中：课程将于 10 月 20 日自动续费 ¥199，由绑定的监护人账户支付。随时可在「我的订阅」中取消。
- 英：Your course renews on Oct 20 for ¥199, charged to the linked guardian account. Cancel anytime in Subscriptions.

未成年人账户发起的购买，文案里要能看出钱是从谁的账户走的，不能让孩子以为「免费」。

## 8. 这个行业的 AI 腔和坏写法

| 坏写法 | 例子 | 改法 |
|---|---|---|
| 千篇一律的最高级表扬 | 「太棒了！完全正确！」不管题目难易、答没答对都用同一句 | 按实际表现分级：「答对了」「这道有点难，你答对了」，难度越高才用越具体的肯定 |
| 愧疚式唤回通知 | 「Duo 很伤心，你已经好几天没来学习了」（仿 Duolingo 被报道过的 "You made Duo sad" 一类提醒） | 只陈述事实加一个简单行动：「3 天没打卡了，今天花 5 分钟接上吧」 |
| 制造攀比焦虑 | 「已经有 2 万人超过你了」「你的好友已经学到第 10 课了」 | 删掉和他人比较的部分，只和自己过去比：「比上周多学了 20 分钟」 |
| 贩卖焦虑的营销语 | 「现在不学，以后就跟不上了」「别人家孩子都在报班」 | 删；换成具体能得到什么：「这门课讲清楚了二次函数的 3 个常见考点」 |
| 用游戏化掩盖真实退步 | 退步了却显示「获得持续进步勋章」 | 诚实展示趋势，进步才给进步类反馈 |
| 家长报告里的排名羞辱 | 「您的孩子在班级排名倒数第 5」 | 改成具体可改进的点：「这次测验里，分式方程相关的题错得比较多」 |
| 不披露 AI 身份 | AI 批改结果用「老师已经看过啦」这种暗示真人老师的说法 | 明确写「AI 已完成批改」，需要人工复核时另外说明 |
| 监考 / 防作弊里的威胁性措辞 | 「作弊将被永久封号，后果自负！！」 | 平实陈述规则和后果，给规则链接：「违反考试规定的，成绩将被标记为无效，可查看《考试管理规定》」 |
| 面向儿童用成人书面语 | 「鉴于你本次测验正确率较低，建议针对性巩固」 | 换成孩子能懂的词：「这几道题还不太熟，我们再练一次」 |
| 打卡 / 学习时长的催促式绑架 | 「再不打卡就要断签了！」「今天还没学够 30 分钟哦」 | 温和提醒，不用负面后果施压：「今天还没打卡，要不要花几分钟学一下？」 |
| 用虚假稀缺或倒计时催报名 | 「仅剩 3 个名额，错过再等一年」 | 如实说明课程容量和开课安排，不编造紧迫感 |
| 空洞的学习口号 | 「让每个孩子都爱上学习」「一站式智慧教育解决方案」出现在功能说明里 | 删，换成这个功能具体做什么 |

## 9. 改前 → 改后

| 改前 | 改后 | 问题 |
|---|---|---|
| 回答错误！正确答案是 B。 | 正确答案是 B，看看解析。 | 「错误！」加感叹号显得严厉，教育场景优先用更轻的否定；「差一点」只在学生确实接近时用，不能对所有错答都说 |
| Wrong! The correct answer is B. | The answer is B. See why. | 同上，英文同理，避免 「Wrong!」 的严厉感 |
| 你太棒了，这道题答对啦！！！ | 答对了。 | 对常规题目用最高级表扬是空洞表扬，留到真正有难度突破时再用 |
| Amazing job!! You got it right!!! | Correct. | 同上 |
| 你已经 3 天没来学习了，Duo 很伤心 | 已经 3 天没打卡了，今天学 5 分钟接上吧 | 愧疚式唤回，教育行业要禁止把学习和角色情绪绑定 |
| You made Duo sad. Come back and learn! | You haven't practiced in 3 days. Pick up where you left off. | 同上 |
| 已经有 2 万人超过你了，加油追上！ | 比上周多学了 20 分钟，继续保持 | 制造攀比焦虑，改成自己和自己比 |
| 20,000 people have passed you! | You've studied 20 more minutes than last week. | 同上 |
| 不报名就会越来越落后 | 这门课讲清楚了二次函数的 3 个常见考点 | 典型的焦虑营销，违反「双减」关于不制造焦虑的精神 |
| 本场考试已开启监考 | 本场考试会录制摄像头和屏幕画面，仅用于违规复核 | 没说清楚监控范围和用途，属于高风险的隐私告知 |
| Proctoring is now active. | This exam records your camera and screen for integrity review only. | 同上 |
| 还剩 2 分钟，请尽快作答 | 还剩 2 分钟，已自动保存到第 8 题，时间到会自动提交 | 没说清楚会不会丢答案，考试场景必须交代保存和提交机制 |
| 您的孩子本周表现不理想 | 孩子本周有 2 次作业迟交、1 次未交 | 对家长的评价性总结换成具体事实，避免定性评判 |
| Your child did poorly this week. | Your child had 2 late and 1 missing assignment this week. | 同上 |
| 系统检测到你作弊 | 系统检测到异常行为，本次成绩标记为「待复核」，可在 7 天内申诉 | 自动判定阶段不能直接定性为「作弊」，要给复核和申诉空间 |

## 10. 审查时加查的项

- [ ] 答错反馈是不是直接给正确答案和解析入口，或用「还没掌握」这类成长型措辞，而不是「错了」「不会」；「差一点」只给确实接近的作答
- [ ] 打卡 / 连续学习提醒有没有攀比或愧疚措辞（和他人比、暗示角色伤心）
- [ ] 作业 / 考试提交前的确认框是否同时写了剩余时间、未完成题数、能不能改
- [ ] 面向儿童的文案句子长度和用词难度有没有超出小学中低年级识字和阅读水平
- [ ] 家长看到的报告是不是事实陈述，没有变成排名羞辱或笼统的负面评价
- [ ] 未成年人模式 / 防沉迷提示有没有说清楚限制的具体内容、解除方式，叫法和监管文件里的「未成年人模式」对齐
- [ ] 监考 / 防作弊说明是否列出了具体监控内容（摄像头 / 录屏 / 人脸），而不是一句「已开启监考」带过
- [ ] AI 批改、AI 老师相关的文案有没有披露 AI 身份，没有让人误以为在和真人老师对话
- [ ] 成绩 / 分数的可见范围文案和实际权限设置一致（本人 / 监护人 / 教师 / 同学分别能看到什么）
- [ ] 营销或引导文案有没有「不用就落后」「保过」「名师押题」这类违反双减 / 广告法精神的表述

## 11. 台港市场差异

适用场景：给台湾、香港的学校系统、线上学习平台、补习和考试类产品写繁体文案。第 6 节里的「未成年人模式」、教育 App 备案、「双减」广告禁令都是大陆制度，台港没有对应名称，不要照搬。只换字、不换词的（老师→老師、课程→課程）不列，见 `locale-zh-hant.md`。

个资：台湾适用《個人資料保護法》（蒐集时依第 8 条告知），香港适用《個人資料（私隱）條例》（Cap. 486），都不是大陆《个人信息保护法》。

### 台湾

**必须出现的话：**

- 年龄分段按法律定义写。「兒童及少年」指未满 18 岁的人；其中「兒童」未满 12 岁，「少年」12 岁以上、未满 18 岁（《兒童及少年福利與權益保障法》第 2 条）。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0050001&flno=2>
- 有讨论区、留言、上传等用户内容的平台，要依防护机制订定自律规范，采取「明確可行防護措施」，例如检举入口、内容分级、限制儿少浏览。主管机关告知内容有害儿少身心时，要限制儿少接取，或先行移除（同法第 46 条；第 1 项所称内容防护机构即 iWIN）。界面上要有看得到的检举入口和处理说明。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0050001&flno=46>
- 蒐集学生个资时，告知第 8 条的六项内容（机关或业者名称、目的、类别、利用期间／地区／对象／方式、权利行使方式、不提供的影响）。<https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0050021&flno=8>
- 未成年人同意要走法定代理人：台湾 18 岁成年（《民法》第 12 条）；未满 18 岁的人订约、授权，原则上要法定代理人允许（《民法》第 77 条）。注册和隐私同意页要有「家長或法定代理人同意」的步骤，不能只让学生自己勾选。<https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=B0000001>
- 生成式 AI 功能：教育部于 114 年 12 月 23 日以臺教資(一)字第 1142704025 號函发布《中小學使用生成式人工智慧注意事項》2.0 版（教师/行政人员/家长版、学生版两份，并搭配《我和 AI 一起學》学习应用手册），明确小学阶段禁止学生独自使用开放式内容生成功能、教师不得将生成式 AI 作为替代性教学主体。据各校转知内容及媒体报道，13 岁以下学生不宜直接使用开放式生成式 AI，13 至 18 岁要在教师或家长指导下使用；原文电子档仅登载于教育部「中小学数位学习精进方案」入口网（<https://pads.moe.edu.tw/download.php>），非公开直链，未能逐字核对全文表述。面向国中小的 AI 功能，要写清楚是否需要老师或家长开通。

**不许出现的话：**

- 「未成年人模式」「青少年模式」：台湾没有这个法定名称。写成具体限制，例如「家長監護設定」「使用時間限制」，并说明谁能解除。
- 大陆考试和学制名称，要换成台湾的：
  - 高考 → 學測／分科測驗
  - 中考 → 國中教育會考
  - 初中 → 國中
  - 小学 → 國小
- 「网课」「班主任」「家长会」：分别换成「線上課程」「導師」「親師座談會」。

**格式要求：**

- 学年写民国「學年度」：115 學年度指 2026 年 8 月起的那一学年，不写「2026–2027 学年」。学期写「上學期／下學期」或「第 1 學期／第 2 學期」，全站统一。
- 年级写「國小三年級」「國二」「高一」。

### 香港

**必须出现的话：**

- 收集学生资料前，向学生和家长发出收集个人资料声明（Cap. 486 保障資料第 1 原則第 (3) 款）。私隐公署指引指出，学校采用网上学习科技、需要收集学生影像或语音时，事前须告知家长和学生；资料只用于教学目的，改作其他用途前要取得「訂明同意」。<https://www.pcpd.org.hk/tc_chi/news_events/media_statements/press_20200402.html>
- 资料当事人是未成年人时，条例容许「有關人士」（对其负有父母责任的人）在特定情况下代为提供订明同意。家长端的同意流程要写明是代谁同意、同意什么。<https://www.elegislation.gov.hk/hk/cap486!zh-Hant-HK>
- 香港没有类似台湾兒少法第 46 条、要求网络平台自订内容防护自律规范的法定义务；教育局就电子学习发布的是操作性指引（如停课期间《运用電子學習模式支援學生在家學習》的参考原则），性质是教学操作建议，不是平台内容自律的强制规定。<https://www.edb.gov.hk/attachment/tc/edu-system/primary-secondary/applicable-to-primary-secondary/it-in-edu/Support/EDB_Guidelines_on_e-learning_at_home_TC.pdf> 涉及学生照片、影片的功能，按私隐公署建议只在校方管理的系统内分享，界面上要说明谁能看到。

**不许出现的话：**

- 大陆和台湾的学制名称，要换成香港的：
  - 高考 → 香港中學文憑試（DSE）
  - 初一 → 中一
  - 小学一年级 → 小一
  - 补习班 → 補習社
  - 作业 → 功課（台湾的「作業」在港也通，但校内通知多写「功課」）
- 「網課」：口语里常见，正式界面写「網上課堂」或「網上學習」。

**格式要求：**

- 学年写「2026/27 學年」，年级写「小一至小六」「中一至中六」。
- 「班主任」在香港照用，不要改成台湾的「導師」；香港的「導師」通常指补习老师或大学 tutor。
