## 1. 什么时候用这份

信号（命中任意两条就用；只命中一条时，结合用户的话判断）：

- 代码 / 依赖：`@shopify/*`、`shopify`、`woocommerce`、`magento`、`saleor`、`medusa`、`stripe`、`taobao-sdk`、`jd-sdk`、`pdd-sdk`、`doudian-open-sdk`、`youzan-open-sdk`
- 目录 / 文件名：`cart/`、`checkout/`、`orders/`、`products/`、`sku/`、`coupons/`、`refunds/`
- 界面里的词：购物车、立即购买、加入购物车、优惠券、满减、到手价、划线价、包邮、七天无理由、退款、售后、预售、定金、尾款、库存、发货、物流、秒杀、会员、自动续费
- 用户的话：「电商网站」「购物车」「商品详情页」「结账流程」「订单页面」「退款售后」「促销活动页」「会员中心」「直播带货」「跨境电商」

和别的行业重叠时：电商 + 金融（支付、分期付款、会员订阅扣款）：支付手续费、分期利率、到账时间这类资金类文案先按 `finance.md` 的硬约束（年化利率、手续费精确展示、确认框五要素），商品、促销、物流、售后仍按本篇；`stripe`、支付宝 / 微信支付类依赖两份文件都会命中，这是预期的重叠，不用二选一，按场景分别适用。电商 + AI（智能客服、搜索推荐、选品助手）：先按本篇的价格 / 库存 / 退款硬约束，再叠 AI 产品「不过度承诺、不编造理由」的措辞规则，优先级：合规 > 诚实 > 转化。

## 2. 语气和人格

- 一句话定调：既要让人想买，又不能靠夸大和制造紧迫感说服；促销词和合规线之间要留余地，数字能验证的地方不用形容词代替。
- 人称：境内 C 端电商多用「你」，品牌官网 / 跨境站视目标市场而定；详情页、营销文案可以热情，但价格、库存、退款、规则类文字（第 6、7 节覆盖的场景）要收住语气，和金融行业一样不能靠感叹号替代信息。
- 能不能用感叹号和 emoji：商品详情、促销 banner、push 文案可以克制使用；订单状态、价格明细、退款进度、规则说明不用——这些地方用户在核对数字和权益，不是在被种草。
- 和 `principles.md` 不同、要覆盖的地方：
  - 「具体」原则在价格、库存、时效类数字上没有模糊空间：到手价、满减门槛、库存件数、发货时效要给确切数字，不写「超值优惠」「库存紧张」这类无法验证的说法（见第 6、7 节）。
  - 空状态在这里经常是营销触点（购物车为空、收藏为空可以带一个入口），但不能把「暂无」类状态写成催促消费的话术；参照 `principles.md` 空状态「现状 + 下一步」，下一步只给一个，不写「去逛逛」「马上囤货」这类催促语。
  - 「不责怪、不卖萌」在客服 / 售后场景尤其重要：退款被拒、商品破损投诉这类场景用户已经不满，卖萌称呼（「亲~」「宝贝」）会放大不满，统一用「你」或平台既定称呼，不单独使用「亲」。
  - 从众心理类文案（「已有 XX 人购买」「XX 人正在浏览」）要用真实数据，不能用固定假数字制造热销假象；这类数字受第 6、7 节关于虚假交易 / 流量数据的硬约束直接管辖，不是单纯的语气问题。

## 4. 术语和叫法

| 用 | 不用 | 说明 |
|---|---|---|
| 加入购物车 | 放入购物车、加购 | 统一动词 + 宾语结构，「加购」是内部黑话，不进用户可见文案 |
| 立即购买 | 马上买、直接买 | 跳过购物车、直接进入下单流程的按钮固定一个词 |
| 到手价 | 实付价、最终价（混用） | 叠加全部当前可用优惠后用户实际要付的价格，站内只留一个叫法 |
| 划线价 | 原价、吊牌价（混用） | 页面上带删除线、仅作比较用途的价格统一叫「划线价」，不直接等同「原价」；是否合规受第 6 节约束 |
| 满减 | 满额减、满额立减（混用） | 单一门槛统一「满减」；多档位要逐档写清楚，不能只写「满减」让用户猜门槛 |
| 满赠 | 买赠、加赠（混用） | 满足条件送商品 / 小样的活动统一「满赠」，和「满减」（减钱）分开，不互相替代 |
| 包邮 | 免邮、运费已含（混用） | 全站一个说法；区域限制（仅限部分省份包邮）要在同一处说明，不能只写「包邮」二字 |
| 运费险 | 退货险（混用） | 购物车 / 确认页勾选的保险产品统一叫「运费险」，和「七天无理由退货」本身分开说明，不能让用户以为买了运费险才能退货 |
| 七天无理由退货 | 无条件退货、随便退 | 固定使用对应法规简化叫法；生鲜、定制等商品本就排除在外，不能写成「无条件」（见第 6 节） |
| 退款 | 退货退款（阶段混用） | 「退款」指资金返还动作本身；「售后」指处理流程（含换货、维修），列表页入口用「售后」，具体阶段状态用「退款中」「已退款」 |
| 预售 | 期货、现货预定（混用） | 明确告知发货时间的预先销售统一「预售」，不用「期货」这类易混淆的金融词 |
| 定金 | 订金（混用） | 法律效力不同的两个词：「定金」依约定可不退，「订金」通常视为预付款、可退。页面写哪个词就要承担哪个词的法律后果，不能图省事混用（见第 7 节） |
| 尾款 | 余款、差额款（混用） | 预售支付的第二笔款项统一「尾款」 |
| 库存 | 现货数量、余量（混用） | 统一「库存」做名词；展示的具体件数必须是真实数字（见第 7 节） |
| 发货 | 揽收、出库（面向用户时混用） | 面向消费者的状态统一「发货」；「揽收」「出库」是物流内部术语，不进用户可见文案 |
| 物流 | 快递、运输（模块名混用） | 统一「物流」做模块名；具体承运商名称（顺丰、中通）照官方名称写 |
| 会员 | VIP（文案混用，图标可保留） | 文案统一「会员」，VIP 可作为视觉标识保留，但说明性文字不混用 |
| 自动续费 | 连续包月、自动扣费（混用） | 周期性扣款的会员 / 订阅服务统一「自动续费」，并按第 6 节要求到期前提示 |
| 规格 | 款式、属性（混用） | 颜色、尺码这类可选规格统一叫「规格」；内部技术词 SKU 不直接暴露给用户 |
| 秒杀 | 抢购、闪购（混用） | 限时限量的大促活动选一个词写进术语表，不要各版块各用各的 |
| 客服 | 在线客服、人工客服（渠道混用） | 入口统一叫「客服」；机器人和人工分流时才分别标注「智能客服」「转人工」 |
| 评价 | 晒单、买家秀（内容类型混用） | 商品评分和文字评论统一叫「评价」；带图 / 视频的用户分享内容才叫「晒单」 |
| 虚拟商品 | 数字商品、电子卡密（混用） | 不支持七天无理由退货的虚拟类商品需要统一叫法，便于在退货规则里单独说明 |
| 分期付款 | 分期、花呗 / 白条（平台专名当通用词用） | 通用功能名用「分期付款」；具体金融产品专名（花呗、白条）只在实际接入对应产品时使用 |
| 发票 | 小票（混用） | 正式报销 / 维权凭证统一叫「发票」；交易成功后的购物小票不是发票，两者法律效力不同，不能互相替代 |
| 正品 | 全新正品、100% 正品（混用） | 承诺商品非仿冒的用语统一「正品」，不叠加「100%」这类绝对化修饰词（见第 6 节禁用项） |
| 保价 | 价格保护（混用） | 购买后一定期限内降价可申请退差价的服务统一叫「保价」，说明适用期限和申请方式，不用「价格保护」这类翻译腔 |
| 换货 | 以换代修（混用） | 质量问题场景更换同款商品统一叫「换货」；「以换代修」是保险 / 家电行业的条款用语，电商场景不借用 |
| 差评 | 低分评价（混用） | 用户给出的负面评价统一叫「差评」，卖家后台的处理流程说明里不用「低分评价」这类委婉说法掩盖性质 |

## 5. 按元素写

只写和通用写法不同的部分。

**按钮**：电商按钮按场景分层——「加入购物车」是不跳转的次要路径，「立即购买」「去结算」「提交订单」「确认支付」才是进入付款流程，不能都写「购买」。收藏 / 关注这类图标按钮的 `aria-label` 要写清楚当前动作和点击后的动作（「收藏」/「取消收藏」），不能留空或写「图标」「按钮」。
中：「加入购物车」不是「购买」的同义词，混用会让人以为点了就下单了。
EN: "Add to cart" vs. "Buy now" — don't collapse both into a single "Buy" button that sometimes adds to cart and sometimes checks out.

**表单标签和校验**：收货地址、手机号这类字段要给具体格式要求，不写「请输入正确格式」。
中：「手机号为 11 位数字」「请选择省 / 市 / 区」。
EN: "Phone number must be 11 digits" — not "Invalid format."

**报错**：库存 / 优惠券失效类报错要分清「现在不能用」和「永久失效」，并给出条件本身。
中：「该商品不满足优惠券使用条件（需满 ¥99）」和「优惠券已过期」是两种不同的错误，不能都写「优惠券不可用」。
EN: "This coupon requires a $14 minimum order" — not "Coupon invalid."

**空状态**：购物车、收藏夹、订单列表为空要分别写，第一次使用、清空、筛选无结果三种情况区分（通用规则见 `principles.md`）；可以带一个浏览入口，但只给一个，不写「去逛逛」「发现好物」这类催促语。
中：购物车为空 →「购物车是空的，去挑选想买的商品」；订单筛选无结果 →「没有符合条件的订单」（不带营销引导）。

**确认框**：下单确认是电商里最高风险的确认框，必须包含商品、数量、到手价、优惠明细、运费、预计发货 / 到达时间，不能只写「确认下单吗？」（展开示例见第 7 节）。取消订单 / 申请退款的确认框要说明是否已付款、退款预计到账时间。

**状态标签**：订单状态固定一套，不能用「处理中」模糊掉「待付款」「待发货」「运输中」「已完成」的区别；物流状态是独立的一套，不要和订单状态混成一套词表。
中（订单状态）：待付款 / 待发货 / 待收货 / 已完成 / 退款中 / 已退款 / 已取消
EN: Pending payment / Processing / Shipped / Delivered / Refunding / Refunded / Cancelled
中（物流状态）：待揽收 / 已揽收 / 运输中 / 派送中 / 已签收 / 揽收失败

**通知 / 推送**：降价、补货、物流提醒要给具体商品和数字，不能只说「有惊喜」「点击查看」诱导点击。
中：「你关注的商品降价 ¥20，现在到手价 ¥199」而不是「好消息！点击查看」。
EN: "Price drop: the item you saved is now $29.99 (was $39.99)." — not "You won't believe this deal! Tap to see."

**进度**：物流状态给实际节点（已揽收 / 运输中 / 派送中 / 已签收），不用无法验证的百分比进度条模拟配送进度。

**引导 / 首次使用**：首单优惠、新人礼包这类引导要说明门槛和有效期，不能只说「新人专享」而不说清楚怎么用、什么时候过期。

**帮助说明**：退货规则、会员权益这类长说明用「查看完整规则」链接到详情页，但第 6 节要求「必须出现」的关键信息（如定金不退、自动续费扣款日）不能只放在链接里，首屏就要有。

## 6. 合规和硬约束

以下硬约束主要依据《中华人民共和国电子商务法》（2018 年 8 月 31 日通过，<https://www.mofcom.gov.cn/zhrmghgdzswf/fg/art/2018/art_cc9187dd95cd40158552d78a610e8c29.html>）、《中华人民共和国消费者权益保护法》（<https://zh.wikisource.org/zh-hans/中华人民共和国消费者权益保护法>）、国务院《中华人民共和国消费者权益保护法实施条例》（国令第 778 号，2024 年 3 月 15 日公布，2024 年 7 月 1 日起施行，<https://www.gov.cn/zhengce/content/202403/content_6940158.htm>）、国家市场监督管理总局《网络交易监督管理办法》（令第 37 号，<https://www.gov.cn/zhengce/zhengceku/2021-03/16/content_5593226.htm>）、《明码标价和禁止价格欺诈规定》（令第 56 号，<https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_9a1f82a007964950a1a0f6c056f2fedf.html>）、《网络购买商品七日无理由退货暂行办法》（<https://zh.wikisource.org/zh-hans/网络购买商品七日无理由退货暂行办法>）、国家互联网信息办公室等七部门《网络直播营销管理办法（试行）》（<https://www.cac.gov.cn/2021-04/22/c_1620670982794847.htm>）、《中华人民共和国广告法》第九条（<https://zh.wikisource.org/zh-hans/中华人民共和国广告法>），条号已逐条核对原文：

**必须出现的话 / 必须做到的披露**：

- 《电子商务法》第十九条：「电子商务经营者搭售商品或者服务，应当以显著方式提请消费者注意，不得将搭售商品或者服务作为默认同意的选项。」——购物车 / 结算页默认勾选的运费险、延保服务一律不能预先勾选。
- 《网络交易监督管理办法》第十八条：自动续费类服务「应当在消费者接受服务前和自动展期、自动续费等日期前五日，以显著方式提请消费者注意，由消费者自主选择」，并「为消费者提供显著、简便的随时取消或者变更的选项」——会员订阅扣款前 5 天必须有提醒，取消入口不能藏。
- 《消费者权益保护法实施条例》第十条第二款：自动展期 / 续费「应当在消费者接受服务前和自动展期、自动续费等日期前，以显著方式提请消费者注意」，和上一条互为补充，两份规定都要满足。
- 《消费者权益保护法实施条例》第二十二条：预付式消费（储值卡、预售定金类）经营者要「与消费者订立书面合同，约定商品或者服务的具体内容、价款或者费用、预付款退还方式、违约责任等事项」，未按约定提供商品或服务的要「按照消费者的要求履行约定或者退还预付款」。
- 《明码标价和禁止价格欺诈规定》第十六条：做价格比较（划线价）时「标明的被比较价格信息应当真实准确」，未标明详细信息的，「被比较价格应当不高于该经营者在同一经营场所进行价格比较前七日内的最低成交价格」——这是「划线价」「原价」最直接的合规依据，没有七日内真实成交记录支撑的划线价就是违规。
- 《网络购买商品七日无理由退货暂行办法》第十条第二款：七日期间「自消费者签收商品的次日开始起算」；第十三条：网络商品销售者「应当在收到退回商品之日起七日内向消费者返还已支付的商品价款」。
- 《网络直播营销管理办法（试行）》第十二条：直播内容「包含可能影响未成年人身心健康内容的，应当在信息展示前以显著方式作出提示」。
- 《消费者权益保护法》第八条：消费者「享有知悉其购买、使用的商品或者接受的服务的真实情况的权利」——商品参数、产地、保质期等信息要主动完整展示在详情页上，不能靠用户自己找客服才能问到。
- 《消费者权益保护法》第二十条：「经营者向消费者提供有关商品或者服务的质量、性能、用途、有效期限等信息，应当真实、全面，不得作虚假或者引人误解的宣传。」——这是第 4、7 节「正品」「材质」类表述要真实可核的上位法依据。

**不许出现的话**：

- 《广告法》第九条：广告不得「使用'国家级'、'最高级'、'最佳'等用语」——商品标题、详情页、促销 banner 一律不能出现「最」「第一」「全网最低」「国家级」这类绝对化用语。
- 《明码标价和禁止价格欺诈规定》第十九条列举的价格欺诈行为，电商场景最常踩的几项：「通过虚假折价、减价或者价格比较等方式销售商品」「使用欺骗性、误导性的语言、文字、数字、图片或者视频等标示价格以及其他价格信息」「不标示或者显著弱化标示对消费者……不利的价格条件」「通过积分、礼券、兑换券、代金券等折抵价款时，拒不按约定折抵价款」。
- 《明码标价和禁止价格欺诈规定》第十七条：不得「没有合理理由」临时抬高标价再做折扣基准，也不得采用「无依据或者无从比较的价格」作比较基准——先涨价再打折的套路直接违规。
- 《消费者权益保护法实施条例》第九条第二款：「经营者不得在消费者不知情的情况下，对同一商品或者服务在同等交易条件下设置不同的价格或者收费标准」——大数据杀熟、千人千价在用户不知情时一律禁止；需要千人千价的场景（会员价、新客价）必须让用户知道定价依据。
- 《网络直播营销管理办法（试行）》第十八条：直播间不得「发布虚假或者引人误解的信息，欺骗、误导用户」，不得「虚构或者篡改交易、关注度、浏览量、点赞量等数据流量造假」；第二十一条：不得「以删除、屏蔽相关不利评价等方式欺骗、误导用户」。
- 《网络交易监督管理办法》第十四条：不得「虚构交易、编造用户评价」，不得「虚构点击量、关注度等流量数据，以及虚构点赞、打赏等交易互动数据」——刷单、好评返现、虚假销量都在禁止之列。
- 《网络交易监督管理办法》第十七条：「不得将搭售商品或者服务的任何选项设定为消费者默认同意，不得将消费者以往交易中选择的选项在后续独立交易中设定为消费者默认选择」——上次购买时勾选过的加购项，不能在下一次下单时自动帮用户勾上。
- 《明码标价和禁止价格欺诈规定》第十九条其余列举的情形，电商促销页同样适用：「谎称商品和服务价格为政府定价或者政府指导价」「以低价诱骗消费者或者其他经营者，以高价进行结算」「无正当理由拒绝履行或者不完全履行价格承诺」——预告的秒杀价、预售价到支付环节不能变相加价或拒不履行。
- 《明码标价和禁止价格欺诈规定》第十八条：赠品应「标示赠品的品名、数量」，若标示价格应为「同一经营场所当前销售价格」——满赠活动页面不能不写赠品数量和品名，也不能虚标赠品价值。

**必须的格式**：

- 价格：人民币用 `¥` 符号，到手价、划线价、优惠后价要分别标注清楚谁是谁，不能让用户自己心算；划线价必须符合上面第十六条的七日最低成交价规则。
- 库存 / 倒计时：展示的库存件数、活动倒计时必须是真实数据，不允许用固定假数字模拟紧迫感——这是行业惯例的硬约束，不是某条法规逐字规定，但第十九条「使用欺骗性、误导性的语言、文字、数字……标示价格以及其他价格信息」的精神同样适用于虚假库存和倒计时（参见第 7 节）。
- 退货商品完好标准（《网络购买商品七日无理由退货暂行办法》第八条）：「商品能够保持原有品质、功能，商品本身、配件、商标标识齐全的，视为商品完好」，合理的查验和调试不影响这一认定——退货规则页写「商品完好」时应说明这个认定标准，不能自行设置比法规更严的「不拆封」门槛。
- 不适用七日无理由退货的商品（同办法第六条）：「消费者定作的商品；鲜活易腐的商品；在线下载或者消费者拆封的音像制品、计算机软件等数字化商品；交付的报纸、期刊」——详情页标注「不支持七天无理由退货」时必须落在这个范围或第七条列举的「拆封后易影响人身安全或者生命健康」「拆封后易导致商品品质发生改变」等情形内，不能自行扩大范围。

**跨境电商专项**：跨境电商零售进口有专门的部门文件——商务部等六部门《关于完善跨境电子商务零售进口监管有关工作的通知》（商财发〔2018〕486 号，<https://www.gov.cn/zhengce/zhengceku/2018-12/31/content_5437823.htm>）。它要求跨境电商企业「会同跨境电商平台在商品订购网页或其他醒目位置向消费者提供风险告知书，消费者确认同意后方可下单购买」，告知书至少包含三项：「相关商品符合原产地有关质量、安全、卫生、环保、标识等标准或技术规范要求，但可能与我国标准存在差异。消费者自行承担相关风险」「相关商品直接购自境外，可能无中文标签，消费者可通过网站查看商品中文电子标签」「消费者购买的商品仅限个人自用，不得再次销售」；平台同时有跨境和国内商家的，要「以明显标识对跨境电商零售进口商品和非跨境商品予以区分，避免误导消费者」；消费者「为跨境电商零售进口商品税款的纳税义务人」，平台、物流企业或报关企业为代扣代缴义务人。所以下单前的风险告知确认、「跨境商品」标识、中文电子标签入口是有文件依据的硬要求。此外，详情页标注清关方式（是否需收件人身份证信息用于申报）、到手价是否已含税费（写明「含税」或「不含税，到付关税约 ¥X」）、物流时效按实际跨境时长给区间、不套用境内发货时效的话术，这几条是行业惯例总结，486 号文没有逐字规定（未核实）。预缴关税和到付关税是两种不同模式：预缴后到手价在付款后不再变动，到付需要用户在收货时另外支付，详情页要写清楚用的是哪一种，不能笼统写「可能产生关税」而不说明谁来付、什么时候付。

## 7. 高风险场景

**价格标示（划线价 / 到手价 / 原价）**：划线价必须有七日内真实成交价支撑；到手价必须是叠加完所有当前可用优惠后的数字，不能是「凑单价」。
中：「划线价 ¥399（近 7 日最低成交价），到手价 ¥279（已减 ¥120，含满减券 ¥50 + 店铺券 ¥70）」
EN: "List price $59.99 (the lowest price in the last 7 days). You pay $41.99 after $18.00 in combined discounts."

**库存和倒计时**：展示的库存数字、限时活动倒计时必须真实，不能为制造紧迫感编造「仅剩 3 件」「还剩 10 分钟」。
中：「库存 128 件」「活动将于 10 月 20 日 24:00 结束」——不写「库存告急，仅剩 3 件」这类无法验证的说法，除非库存确实是 3 件。
EN: "128 in stock." — not "Only 3 left!" unless that's the actual count.

**预售定金不退**：下单页在用户支付定金前就要说明定金是否可退、尾款支付窗口、发货时间，不能等用户付完定金才告诉他们不能退。
中：「定金 ¥50，不支持退款；尾款需在 11 月 1 日 00:00–23:59 内支付，预计 11 月 10 日发货」
EN: "Deposit: $7 (non-refundable). Pay the balance between Nov 1, 12:00 AM and Nov 1, 11:59 PM. Estimated shipping: Nov 10."

**自动续费会员**：开通页要显示首次扣款日期、续费金额、取消方式，扣款前 5 天要有提醒（《网络交易监督管理办法》第十八条），取消入口不能藏在三级菜单里。
中：「¥19/月，首次扣款在你确认开通时发生，之后每月 15 日自动续费，到期前 5 天会提醒你，随时可在「会员设置」取消」
EN: "$2.99/month. First charge happens when you confirm. Renews on the 15th each month — we'll remind you 5 days before, and you can cancel anytime in Membership settings."

**退款时效和路径**：给清楚的时间线、金额、退回方式，拒绝退款要说明依据。
中：「退款已发起，预计 1–3 个工作日原路退回，可在「退款详情」查看进度」；拒绝时：「退款申请未通过：商品不在七天无理由退货范围内（定制类商品），如对商品质量有异议可申请售后维修」
EN: "Refund initiated. Expect it back on your original payment method in 1–3 business days." / "Refund request denied: this item is excluded from the 7-day return window because it's custom-made. If there's a quality issue, you can request a repair instead."

**优惠叠加规则**：说清哪些优惠能叠加、哪些互斥，不要等结算页才让用户发现券用不了。
中：「满减券和店铺优惠券可叠加，平台津贴与会员折扣不可同时使用」
EN: "Coupons and store discounts can be combined. Platform credits can't be combined with membership discounts."

**直播带货实时下单**：直播间商品价格、库存、优惠要和商品详情页一致，用「直播间专属价」时必须说明仅限本场，不能让用户以为任何时候进来都是这个价。
中：「直播间专享价 ¥99（仅限本场，详情页日常价 ¥129）」
EN: "Live-stream price: $13.99 (this broadcast only; regular price $16.99)."

**跨境关税 / 清关时效**：到手价要说明是否含税，物流时效要给跨境实际区间，不能用境内物流的话术。
中：「到手价已含进口税，预计 7–15 个工作日海外直发到货，清关时效可能受海关抽检影响」
EN: "Price includes import duties. Estimated delivery 7–15 business days from overseas; customs inspection may add time."

**正品 / 假一赔十承诺**：承诺商品非假货要具体说明依据（官方授权、品牌直供），「假一赔十」这类赔付承诺要在规则页说明如何界定假货、如何申请赔付，不能只喊口号。
中：「本店为 XX 品牌官方授权店铺；如经鉴定为假货，按实际支付金额十倍赔付，详见《正品保障规则》」
EN: "Authorized retailer of [Brand]. If an item is verified counterfeit, compensation is 10x the amount paid — see the Authenticity Policy for details."
说明：《消费者权益保护法》第五十五条规定的法定欺诈赔偿是价款的三倍（不足 500 元按 500 元计，俗称「假一赔三」）；商家承诺的「假一赔十」是高于法定标准的自愿承诺，一旦写出就构成要兑现的承诺，不能当营销噱头喊完就不认。

**保价 / 价格保护**：说明保价期限、申请入口、能否叠加其他优惠对比降价后价格，不能承诺「随时保价」却不说截止时间。
中：「支持 7 天保价：购买后 7 天内降价，可在「我的订单」申请退差价」
EN: "7-day price match: if the price drops within 7 days of purchase, request the difference under 'My Orders.'"

**千人千价 / 会员专享价**：向不同用户展示不同价格时，必须让用户知道定价依据，不能让用户在不知情时看到和别人不一样的价格（对应第 6 节「经营者不得在消费者不知情的情况下……设置不同的价格」）。
中：「会员价 ¥89（普通价 ¥99，会员专享）」
EN: "Member price: $12.99 (regular price $14.99, members only)." — not a silently different price with no stated reason.

## 8. 这个行业的 AI 腔和坏写法

| 坏写法 | 例子 | 改法 |
|---|---|---|
| 用绝对化用语做促销 | 「全网最低价」「史上最大折扣」 | 删掉绝对化词，给可验证的比较基准：「近 7 日最低价」 |
| 假库存制造紧迫感 | 「库存紧张，仅剩 2 件」（实际库存充足） | 展示真实库存数字，库存多就写多 |
| 假倒计时 | 活动结束后页面倒计时重新开始 | 倒计时必须对应真实的活动结束时间，结束后下架或明确写「活动已结束」 |
| 把「划线价」包装成「原价」 | 「原价 ¥999，现价 ¥199」（¥999 从未真实售卖过） | 「划线价 ¥999（近 7 日未实际成交）」或直接去掉无依据的划线价 |
| 卖萌称呼掩盖售后问题 | 「亲，宝贝可能物流小哥摔了呢~」 | 直接说清问题和处理方案：「商品在运输中损坏，可申请换货或退款」 |
| 优惠叠加规则藏到结算页才说 | 购物车显示「满 300 减 50」，结算页才发现会员折扣不能一起用 | 商品页 / 购物车就标注互斥规则 |
| 用「预计」包装成承诺却没有后续机制 | 「预计明天送达」（实际经常延迟且不提示） | 给时间区间，超时要主动告知：「预计 10 月 18 日送达，物流延迟会短信通知你」 |
| 自动续费入口故意做小 | 会员页突出「立即开通」，取消按钮藏在三级设置里 | 开通和取消入口同等可发现，按第 7 节给全信息 |
| 把「定金」和「订金」混着用 | 预售页写「订金 ¥50 不可退」 | 法律含义不同的两个词选一个固定使用，「定金不退」要用「定金」这个词 |
| 用营销话术回复投诉 | 客服机器人对退款请求回复「感谢你对我们的支持，期待下次购物」 | 直接处理请求或说明处理进度，不在投诉场景里放感谢 / 营销语 |
| 用现金或流量倾斜引导好评 | 「晒单返现 5 元，好评优先展示」 | 不以现金或流量倾斜引导特定方向的评价（见第 6 节禁用项） |
| 折扣比例基于虚构基准价计算 | 「到手价仅为日常价的 1 折」（日常价本身是虚构的） | 划线价必须有真实依据，折扣比例基于真实划线价计算 |
| 用「正品」「假一赔十」当口号却不说依据 | 「100% 正品，假一赔十」 | 「XX 品牌官方授权店铺；如经鉴定为假货，按实际支付金额十倍赔付，详见《正品保障规则》」 |
| 保价承诺没有期限 | 「随时保价，放心购买」 | 「支持 7 天保价：购买后 7 天内降价可申请退差价，超过 7 天不再支持」 |
| 把差评处理说成单纯的「情绪安抚」 | 客服对差评留言回复「谢谢你的反馈，祝你生活愉快」 | 具体回应差评指出的问题，并说明处理方案：「已为你核实到商品破损问题，支持换货或退款」 |

## 10. 审查时加查的项

- [ ] 划线价 / 原价是否有近 7 日真实成交记录支撑，而不是凭空设置后打折
- [ ] 到手价是否已叠加全部当前可用优惠，购物车和结算页的数字是否一致
- [ ] 库存数字、活动倒计时是否真实，而不是固定的「仅剩 X 件」话术
- [ ] 预售商品是否在支付定金前就说明定金是否可退、尾款窗口、发货时间
- [ ] 自动续费 / 会员订阅是否披露首次扣款时间、续费金额、周期，扣款前是否有提醒，取消入口是否和开通入口同样好找
- [ ] 优惠叠加 / 互斥规则是否在购物车或商品页就说明，而不是等结算页才告诉用户
- [ ] 文案中是否出现「最」「第一」「全网最低」「国家级」等广告法禁用的绝对化用语
- [ ] 退货规则页标注的「不支持七天无理由退货」商品范围是否落在法规列举的范围内，而不是自行扩大
- [ ] 直播间价格 / 库存与商品详情页不一致时，是否说明「仅限本场」等限定条件
- [ ] 退款 / 拒绝退款是否给出清楚的时间线、金额、依据，而不是「退款失败」「申请未通过」这类没有下一步的话
- [ ] 「正品」「假一赔十」「保价」这类承诺是否说明了认定依据、赔付方式和有效期限，而不是只喊口号
- [ ] 会员价 / 千人千价这类针对不同用户的差异化价格，是否向用户说明了定价依据（会员身份、新客身份），而不是静默展示不同数字

## 11. 台港市场差异

界面是 zh-TW（台湾）或 zh-HK（香港）时读这一节，第 6、7 节里大陆的法规在台港都不适用，按下面的规则替换。通用换词（購物車写法不变、資訊 / 訊息等）见 `locale-zh-hant.md`，这里只列电商专有的。

### 台湾

- 七日解除权依据《消費者保護法》第19條：通讯交易消费者「得於收受商品或接受服務後七日內，以退回商品或書面通知方式解除契約，無須說明理由及負擔任何費用或對價」——这是「七天」概念本身的法律来源，界面可用「七日猶豫期」或民间惯用的「七日鑑賞期」，法条原文未用「鑑賞期」一词，全站选一个固定叫法。
- 排除七日解除权的「合理例外情事」（依《通訊交易解除權合理例外情事適用準則》，转引自消费者文教基金会文章，具体条号对应官方最新公告版本未直接核实，上线前建议在 law.moj.gov.tw 核对）：易於腐敗 / 保存期限較短商品、依消費者要求的客製化給付、報紙期刊雜誌、已啟封之影音商品或電腦軟體、非以有形媒介提供的數位內容或線上服務、已拆封之個人衛生用品。商品详情页标注「不适用七日解除权」时要落在这六类之一，并提前告知消费者。
- 格式：金额写「新臺幣 1,280 元」或「NT$1,280」，一般不带小数（惯例）。
- 划线价 / 价格比较：未查到台湾专门对应大陆《明码标价和禁止价格欺诈规定》的细则（没有「前七日最低成交价」这类量化规则），比价类文案按《公平交易法》第 21 條处理，原文：「事業不得在商品或廣告上，或以其他使公眾得知之方法，對於與商品相關而足以影響交易決定之事項，為虛偽不實或引人錯誤之表示或表徵。」第二项明确这些事项「包括商品之價格、數量、品質、內容……」（<https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0150002>）。公平會《對於網路廣告案件之處理原則》（2023 年 2 月 21 日修正发布）第八點第（一）款把「廣告所示價格、數量、品質、內容及其他相關交易資訊等與事實不符」列为网络广告虚伪不实或引人错误的类型，第十點：「事業違反第八點及第九點，可能構成公平交易法第二十一條之違反」（<https://www.ftc.gov.tw/internet/main/doc/docDetail.aspx?uid=165&docid=12231&mid=165>）。个案尺度上线前建议再比对公平交易委员会的处分书。

### 香港

- 《商品說明條例》（香港法例第362章）禁止「虛假達關鍵程度的商品說明，以及雖非虛假但卻具有誤導性達關鍵程度的商品說明」，适用货品和服务；违者最高可被罰款 $500,000 及監禁 5 年——比大陆对应条款的刑责更重，商品详情页的材质、产地、功能描述要和实物一致，促销页的折扣、赠品条件要和实际一致，不能用模糊措辞留后路。
- 划线价 / 价格比较：未查到香港专门对应大陆《明码标价和禁止价格欺诈规定》的细则，比价类促销文案按《商品說明條例》对虚假或具誤導性商品說明的一般性禁止处理即可，不需要另找专门的比价规则。
- 个资：台湾适用《個人資料保護法》，蒐集个资时按第8條告知六项（机关名称、蒐集目的、个资类别、利用的期间 / 地区 / 对象 / 方式、当事人权利、不提供的影响）；香港适用《個人資料（私隱）條例》（第486章），收集时按附表1第1原則告知收集目的和资料转移对象，用于直接促销前要先通知并取得同意（第6A部）。不要写成大陆《个人信息保护法》的说法。
